# Repository Guide

- This repository builds `davidojeda.dev` with Eleventy, Nunjucks, and Tailwind CSS.
- Use Node.js 24.19.0 and npm 11.17.0.
- Use `npm run dev` for local development.
- Edit source files. Do not edit `_site/` or `node_modules/`.
- Keep David's prose unchanged unless the task requires a content change.
- Keep the existing CommonJS format and two-space indentation.
- Before you finish, run `npm test`.
